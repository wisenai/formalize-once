# Third-party code and data

- `data/raw/rulearena/` vendors the reference computations, rule texts, and public
  problem sets of **RuleArena** (Zhou et al., ACL 2025),
  https://github.com/SkyRiver-2000/RuleArena, unmodified, under its MIT license.
- MedCalc-Bench (Khandekar et al., 2024) calculator implementations are **not**
  redistributed here (no upstream license); `sscramble download` fetches them from
  https://github.com/ncbi-nlp/MedCalc-Bench.
